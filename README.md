# GAT350-NB

OpenGL Graphics Project for GAT350  
*Created by BaconEater314*

## 🧾 Overview

This repository contains an OpenGL graphics application built in C++ for the GAT350 course. It includes source code and build files to compile and run a basic OpenGL rendering project, covering topics such as shaders, rendering pipelines, and graphics fundamentals.

## 📁 Project Structure

```
/Build/                — Build files and project configuration  
/Source/               — C++ source code  
OpenGL.sln             — Visual Studio solution file  
.gitattributes        
.gitignore            
```

## 🛠 Requirements

- C++17 compatible compiler  
- OpenGL development environment  
- Visual Studio (recommended) or any IDE that supports `.sln` files  

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/BaconEater314/GAT350-NB.git
   ```

2. **Open the Solution**
   - Launch `OpenGL.sln` in Visual Studio.

3. **Build & Run**
   - Build the solution.
   - Run the project to see the graphics application in action.
